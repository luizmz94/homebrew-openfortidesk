# TunnelMac Homebrew tap

Homebrew tap for [TunnelMac](https://github.com/luizmz94/tunnelmac) (formerly
OpenFortiDesk), a native macOS GUI for the original
[openfortivpn](https://github.com/adrienverge/openfortivpn) and for OpenVPN profiles.
Not affiliated with Fortinet, OpenVPN or the openfortivpn project.

```sh
brew install --cask luizmz94/tunnelmac/tunnelmac
```

Or tap first:

```sh
brew tap luizmz94/tunnelmac
brew install --cask tunnelmac
```

Requires Apple Silicon and macOS 13 or later. openfortivpn is installed from
Homebrew as a dependency. On first use, open TunnelMac, activate its service,
approve it in System Settings and approve the protected openfortivpn/OpenVPN runtime.

Coming from OpenFortiDesk: remove its service (Configurações… > Serviço privilegiado
> Remover serviço), quit it, run `brew uninstall --cask openfortidesk` and
`brew untap luizmz94/openfortidesk`, then install `tunnelmac`.

## Upgrade and uninstall

```sh
brew upgrade --cask luizmz94/tunnelmac/tunnelmac
brew uninstall --cask luizmz94/tunnelmac/tunnelmac
```

Before Homebrew replaces or removes the app, the cask runs the installed app's fixed
maintenance command as your user. It asks the app to quit normally (you can cancel),
waits for VPN cleanup and unregisters the background service. If cleanup is pending,
the service is unreachable or unregistering fails, the upgrade or uninstall stops
without removing the app. Do not force it, and do not reopen the app meanwhile.

Profiles, Keychain secrets and the protected runtime survive uninstall. No `zap` is
provided; see the app's README to remove the managed runtime.

## Maintenance

`Casks/tunnelmac.rb` is generated by `scripts/update-tap.py` in the app repository
from a **published** release, after verifying the download checksum, signature,
notarization and architecture. Do not edit the version or checksum by hand.
